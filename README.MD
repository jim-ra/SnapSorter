Introduction

SnapSorter grew out of my experience building several SJSeth Solutions AI Optical Sorters (v7.1). When I found a few cases I had missed during sorting, I started experimenting with a way to separate cases of similar diameter by height. My first solution used a few additions to the build and, yes, rubber bands.

That experiment led to nearly a year of redesign and prototyping before I built the first SnapSorter v1. I began the patent process in September 2025, but later decided that making SnapSorter open source would be more useful. I wanted others to be able to build one, adapt it to their needs, and improve the design.

In September 2026, we introduced SnapSorter v2. It is a more stable and capable design, with a direct drive 42GP-775 motor replacing the original gear driven 10 kg·cm motor. The new 16 RPM motor is rated at 120 kg·cm of torque (approximately 104 lb·in). We also added a friction clutch to help protect the mechanism if a case jams.

Files will be released soon, that will provide source for hardware, and STL files of all parts needed.
